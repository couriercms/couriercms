# Support

CourierCMS is an early-stage, community-supported project. The project does
not currently promise response times, compatibility periods, or free
implementation support.

## Questions and troubleshooting

Start with the [documentation](docs/README.md), especially the
[development setup](docs/development/setup.md) and
[operations guides](docs/operations/). Search existing issues before opening
a new one.

Use the appropriate GitHub issue form for a reproducible bug or a concrete
feature proposal. Sanitize logs and configuration before posting. General
questions may be closed if they cannot be turned into actionable project work.

Do not report vulnerabilities, credentials, private content, or other
sensitive information in a public issue. Follow [SECURITY.md](SECURITY.md).

## Professional services

Community participation does not create a consulting or support agreement.
Professional architecture, implementation, extension development, migration,
and operational services may be offered separately from the open-source
project.
